
# TaskFlow — To-Do List App

A simple, interactive, and responsive To-Do List application built using HTML, CSS, and JavaScript. TaskFlow helps users manage daily tasks with an easy-to-use interface and automatic browser storage.

## Features

- **Create Tasks:** Add new tasks to your list.
- **Read Tasks:** View all your saved tasks.
- **Update Tasks:** Edit task descriptions whenever needed.
- **Delete Tasks:** Remove individual tasks.
- **Mark as Completed:** Mark tasks as completed or active.
- **Task Filtering:** Filter tasks by All, Active, and Completed.
- **Local Storage:** Automatically saves tasks in the browser.
- **Task Statistics:** View total, active, and completed task counts.
- **Clear Completed:** Remove all completed tasks at once.
- **Responsive Design:** Works on desktop and mobile screens.
- **Empty State Messages:** Helpful messages when no tasks are available.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Browser Local Storage API

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/satyamPrajapati96/todo-list.git
   ```

2. Open the project folder:

   ```bash
   cd todo-list
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No additional packages or build tools are required.

## How to Use

1. Enter a task in the input field.
2. Click **Add Task** to create it.
3. Use **Edit** to update a task.
4. Use the checkbox to mark a task as completed or active.
5. Use the filters to view all, active, or completed tasks.
6. Click **Delete** to remove a task.
7. Click **Clear completed** to remove all completed tasks.

Your tasks are saved automatically in your browser using Local Storage and remain available after refreshing the page in the same browser.
